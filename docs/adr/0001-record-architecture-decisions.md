# 1. Record architecture decisions

Date: 2026-09-13
Status: Accepted

## Context
We need a durable record of significant technical choices and their rationale.

## Decision
We will keep short ADRs (Architecture Decision Records) in `docs/adr/`,
one file per significant decision, numbered sequentially.

## Consequences
Reviewers can trace *why* each choice was made. This satisfies the M5
documentation requirement and the "document every assumption" ground rule.
